# IDS — Intuition Design System (вендорная копия)

Источник: https://github.com/intuition-tech/ids, коммит 612a606 (2026-07-14). Лицензия MIT — см. LICENSE.
Справочник: https://intuition-tech.github.io/ids/ · https://intuition.team/ru/ids

Файлы в этой папке не правим — это копия апстрима. Всё своё (палитра, семантика,
отступы портфолио) лежит рядом, в `src/styles/tokens/`, и переопределяет токены IDS.
Чтобы обновить IDS: заново скопировать `css/`, `js/`, `docs/` из апстрима и поправить коммит выше.
Не скопированы: демо-страницы, картинки, архивы, шрифт Inter (у нас Inter Tight), PhotoSwipe.
