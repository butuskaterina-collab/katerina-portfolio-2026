# katerina-portfolio-2026

Сайт-портфолио Катерины Бутусовой. Astro, публикация через Vercel из ветки `main`.

```bash
npm install
npm run dev      # локально: http://localhost:4321
npm run build    # сборка в dist/
```

- `src/components/` — части страниц (шапка, главная, подвал)
- `src/i18n/ui.ts` — тексты интерфейса на русском и английском
- `src/data/selected.ts` — избранные проекты на главной
- `src/assets/` — изображения (сжимаются автоматически при сборке)
